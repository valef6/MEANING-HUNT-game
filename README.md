Topic: Game

Name: "MEANING HUNT"

I´ve noticed that in programming fundamentals there is a lot of vocabulary, concepts and signs like input, int, string, float, print, //, %, *, that can be really easy to forget about, because of this many students make mistakes on exams. Sometimes we as students understand the logic of the problem but we forget about the words or symbols that we have to use. That´s why my target users are students from first semester that are in programming fundamentals.

My idea is to create a game called "MEANING HUNT", the idea is that the program shows the definition of a word or sign, and the player has to guess the correct term. I think this is interesting because it transforms studying into an active game. Instead of just reading notes. It makes learning more fun and helps to memorize the vocabulary and signs, also, I think that the score would keep the students engaged while they are learning, which is important because programming can be boring when you don´t understand it at the beginning.

ALGORITHM

INPUT

-Player´s name

-Player´s answer

PROCESS

-Start

-Create a list and matrix with terms and their definitions

-Set score=0 and Total=0

-Pick a random definition from the matrix

-Show the definition to the player

-Ask the player "What is the correct term?"

-Compare the player´s answer with the correct term

-If the answer of the player is correct, score +1

-If the answer of the player is incorrect, show the correct answer

-Ask if the player wants to play again.

-If yes, go back to the step of picking a random definition from the matrix

-If no, finish the game

OUTPUT

-Show correct or wrong to the player

-Show final score

-Finish the game
